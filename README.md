# Crypto Factor Research

A systematic study of cross-sectional and time-series factors in the cryptocurrency market, built from scratch on exchange data. The project tests classic equity-factor methods on ~31 major crypto assets, with rigorous controls for lookahead bias, survivorship bias, and transaction costs — and honestly reports where these factors work and where they fail.

**Data:** Daily OHLCV for ~31 major USDT pairs from Binance (via `ccxt`), 2020–2026.

---

## Key Findings

**1. Cross-sectional factors are weak in crypto — and I show why the "obvious" reading is wrong.**
Momentum, volatility, and reversal factors all have small IC (|IC| ≤ 0.07). The volatility factor showed an apparent contradiction: negative IC (−0.07) yet the highest-volatility group had the *highest mean* return. Root cause: crypto returns are extremely right-skewed — the high-volatility group is dominated by meme/small-cap coins that mostly fall but occasionally explode, inflating the *mean*. Median return and IC (rank-based) both correctly show the high-volatility group performs worst. **Takeaway: in crypto factor research, mean-based metrics are systematically misleading; IC and median are the robust choices.**

**2. The low-volatility anomaly exists but is not tradable via a long-short portfolio.**
A long-low-vol / short-high-vol portfolio lost ~97% (NAV 0.026 gross, 0.013 after costs). Decomposition: the long leg (low-vol) returned +505% (Sharpe 1.06), while the short leg (high-vol) went to zero. Shorting high-volatility coins means shorting the right tail — a single meme-coin spike wipes out the short leg. **The classic long-short hedging framework fails in a right-skewed market.**

**3. The low-vol long leg is market beta, not alpha.**
After stripping beta (vs an equal-weight benchmark), the low-vol long leg *underperforms* the benchmark (Sharpe 1.06 vs 1.22, excess Sharpe −0.40). Out-of-sample Sharpe collapses from 1.73 to −0.25 — the effect is not persistent.

**4. Time-series momentum works where cross-sectional momentum fails.**
On the same universe, a time-series momentum strategy (long if past-90d return > 0, else short) reached NAV 2.53 (2.05 after costs), while cross-sectional momentum barely cleared 1.0 (fair ±1 comparison: 2.53 vs 1.32). Win rate is only 34% — typical of trend strategies that profit through a high payoff ratio, not high hit rate. Robust across 30/60/90/180-day lookbacks (all > 1); shorter windows perform best, consistent with crypto's fast trend turnover. Returns concentrate in trending regimes and weaken out-of-sample (in-sample NAV 1.78 vs out-of-sample 1.15).

**5. The volatility factor is independent of size.**
Market-cap neutralization (regressing the factor on log dollar-volume cross-sectionally, taking residuals) leaves IC essentially unchanged (−0.071 → −0.065), confirming the volatility signal is not a small-cap effect in disguise.

## Methodology

- **Lookahead control:** every factor is `shift(1)` so a signal computed on day *t*'s close is only used from *t+1*; missing values are forward-filled only (never backward).
- **Transaction costs:** turnover × 0.1% per side; time-series turnover ≈ 0.33/day, and daily rebalancing costs materially erode the long-short NAV.
- **Robustness:** in-sample / out-of-sample split (70/30) and multi-window parameter sweeps to guard against overfitting.
- **Neutralization:** cross-sectional OLS to strip a chosen exposure (here, size) from a factor.
- **Known limitation — survivorship bias:** the universe is selected from currently-listed pairs, so delisted/collapsed coins (e.g. LUNA) are excluded, which upward-biases returns. Mitigating this requires point-in-time constituent data.

## Repository Structure

```
crypto-factor-research/
├── README.md
├── requirements.txt
├── data/                     # generated by the pipeline (git-ignored)
├── src/
│   ├── scraper.py            # pull OHLCV from Binance via ccxt
│   ├── dataclean.py          # build wide tables, diagnose & drop bad tickers
│   └── factor.py             # momentum / volatility / reversal + liquidity filter
└── notebooks/
    ├── backtest.ipynb   # multi-factor test, mean-vs-median, long-short, neutralization
    └── backtest2.ipynb       # time-series momentum, robustness, TS-vs-CS comparison
```

## How to Run

```bash
pip install -r requirements.txt
python src/scraper.py       # fetch raw OHLCV -> data/
python src/dataclean.py     # clean -> data/close_clean.csv, volume_clean.csv
python src/factor.py        # build factors -> data/*_factor.csv
# then run the notebooks in order
```

## Notes

This project prioritizes methodological rigor over headline returns. Several results are negative or falsify a strategy — reported as-is, because in factor research a clean falsification is as valuable as a positive result. Core techniques (IC/IR, quantile backtests, long-short construction, beta stripping, cross-sectional neutralization, out-of-sample validation) are implemented from scratch.
